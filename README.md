# medtracker
Web-based medicine inventory &amp; expiry tracker for healthcare facilities. React 18 + Spring Boot + Spring Security + PostgreSQL. 4 roles (Admin/Pharmacist/Viewer/User), barcode lookup (ZXing + OpenFDA), AI label extraction (Groq Vision), expiry &amp; low-stock email alerts. Monitoring via Prometheus, Grafana, Zipkin. Dockerized, deployed on Azure.
